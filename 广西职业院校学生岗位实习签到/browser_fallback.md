# 广西职业院校学生岗位实习浏览器兜底操作手册

## 适用场景
直连签到失败（网络错误、接口变更、token过期等）时，使用浏览器手动完成签到。

## 操作步骤

### 1. 登录
浏览器访问系统登录页
- 输入账号和密码
- 点击「登录」按钮

### 2. 进入签到页
登录后自动跳转到首页，点击底部或菜单中的「签到」

### 3. 完成签到
- 页面会请求获取定位权限，点击「允许」
- 点击「签到」按钮
- 签到成功后显示签到成功提示

### 4. 查看签到记录
访问签到页可查看历史签到记录

## 注意事项
- 签到需要定位权限，浏览器会请求获取位置信息
- 签到范围为公司坐标周围约 400 公里
- 每日只能签到一次

## 接口说明（供自动化参考）

| 步骤 | 方法 | 接口 | 说明 |
|------|------|------|------|
| 登录 | POST | /api/studentapp/Login | UserName, Password |
| 学生信息 | POST | /api/studentapp/Info | 含SignToday状态 |
| 签到设置 | POST | /api/studentapp/Settings | 含公司坐标和签到范围 |
| 签到 | POST | /api/studentapp/Sign | Lat, Lng（虚拟定位） |
| 签到日志 | POST | /api/studentapp/SignLog | 历史签到记录 |
