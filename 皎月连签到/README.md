# 皎月连每日自动签到

## 概述
为皎月连一键内网穿透（https://www.natpierce.cn/）搭建每日自动签到系统，延长服务到期时间。

- 签到奖励：每次签到延长 24 小时服务期
- 执行时间：每天 10:30
- 核心特点：服务未到期时直连检查即可，到期时需网易易盾验证码

## 文件结构
```
皎月连签到/
├── config.json           # 账号配置（权限600，不提交）
├── signin_direct.py      # 直连状态检查脚本
├── run_checkin.sh        # 签到运行入口
├── browser_fallback.md   # 浏览器兜底操作手册
├── README.md             # 本文件
└── signin.log            # 签到日志（自动生成，不提交）
```

## 方案说明

### 直连方案（当前主用）
- 使用 requests 登录并检查签到状态
- 仅做状态检查，遇到验证码时不尝试绕过
- 服务未到期时直接返回"无需签到"

### 浏览器兜底
- 直连检测到需要验证码时，按 browser_fallback.md 手动操作
- 需要人工完成网易易盾滑块/点选验证

## 签到逻辑
皎月连采用"服务到期才需签到"机制：
- 服务未到期 → 预检查返回 400 "服务尚未到期，无需签到" → 直接通过
- 服务到期 → 预检查返回 200 → 弹出验证码 → 验证通过后签到
- 每次签到延长 24 小时服务期

因此每天定时运行时，大部分情况会直接返回"无需签到"，只有服务快到期时才需要真正签到。

## 接口说明

| 接口 | 方法 | 用途 |
|------|------|------|
| /pc/login/login.html | POST | 登录（username, password） |
| /pc/sign/index.html | GET | 签到页（含下次可签到时间、服务到期时间） |
| /pc/sign/qiandao_bf.html | POST | 签到预检查（200=需验证码，400=无需签到） |
| /pc/sign/qiandao.html | POST | 实际签到（验证码通过 cookie 传递） |

## 使用方法

### 手动运行
```bash
cd 皎月连签到
./run_checkin.sh
```

### 查看日志
```bash
tail -20 signin.log
```

## 依赖
- Python 3.8+
- requests

## 安全提醒
- config.json 包含账号密码，权限已设为 600，不提交到 Git
- 不在日志或回复中泄露密码
- 登录态基于 PHPSESSID，每次运行重新登录
