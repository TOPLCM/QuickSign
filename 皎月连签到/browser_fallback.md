# 皎月连浏览器兜底操作手册

## 适用场景
直连签到返回退出码 2（需要网易易盾验证码）时，使用浏览器兜底完成签到。

## 操作步骤

### 1. 打开签到页面
浏览器访问：https://www.natpierce.cn/pc/sign/index.html

### 2. 确认登录态
- 页面右上角应显示你的邮箱
- 如未登录，访问 https://www.natpierce.cn/pc/login/login.html 完成登录

### 3. 点击签到按钮
- 页面中间有一个「签到」按钮（id="qiandao"）
- 点击后会弹出网易易盾验证码

### 4. 完成验证码
- 网易易盾验证码可能是滑块拖动或文字点选
- 按提示完成验证

### 5. 确认签到成功
- 验证码通过后自动调用签到接口
- 页面刷新，显示「下次可签到时间」为明天
- 即表示签到成功

## 接口说明（供自动化参考）

| 步骤 | 方法 | 接口 | 说明 |
|------|------|------|------|
| 预检查 | POST | /pc/sign/qiandao_bf.html | 返回 code=200 则需验证码 |
| 实际签到 | POST | /pc/sign/qiandao.html | 需携带验证码 validate 参数 |

## 注意事项
- 签到按钮点击后先调用 qiandao_bf，通过后才弹出验证码
- 验证码 validate 参数由网易易盾 JS SDK 生成，无法手动构造
- 服务到期前签到可延长服务期，服务未到期时预检查返回"无需签到"
